# 不动产交易及持有环节税费计算工具

一个**纯前端**的不动产税费测算工具，覆盖 **交易环节（卖方 / 买方）** 与 **持有环节** 的主要税种，内置地区参数解析与政策依据文档，支持计算结果导出 CSV。

> 无需安装、无需构建、无后端依赖 —— 一个 `index.html` 打开即用。

---

## ✨ 功能特性

- **全环节覆盖**：交易环节（卖方 4 类税 + 买方 3 类税）+ 持有环节（2 类税）
- **主体差异化计算**：区分企业 / 个人 / 合伙企业等主体类型，适用不同税率与计税方式
- **地区参数解析**：内置城市级参数（契税税率、土地等级、附加税率等），未覆盖地区支持手工填写
- **历次取得场景**：支持"自建 / 购置 / 继承 / 赠与"等取得方式，自动判断持有年限与发票年限
- **明细可追溯**：每项税额展示计税依据、税率、计算过程
- **政策依据内置**：所有计算规则均可对照 `docs/` 中的政策文档
- **一键导出 CSV**：计算结果可导出为表格，便于存档或二次分析

## 📊 覆盖税种

### 交易环节 — 卖方

| 税种 | 说明 |
|:-----|:-----|
| 增值税及附加 | 区分住房/非住房、持有年限、纳税人类型（一般/小规模） |
| 土地增值税 | 四级超率累进，支持核定征收与据实清算 |
| 印花税 | 产权转移书据 |
| 所得税 | 企业所得税 / 个人所得税（含核定与据实） |

### 交易环节 — 买方

| 税种 | 说明 |
|:-----|:-----|
| 契税 | 按套数、面积、地区适用差别税率 |
| 印花税 | 产权转移书据 |
| 增值税 | 特定情形下买方承担 |

### 持有环节

| 税种 | 说明 |
|:-----|:-----|
| 房产税 | 从价计征 / 从租计征 |
| 城镇土地使用税 | 按土地等级与占用面积计征 |

## 🚀 使用方式

### 方式一：直接打开（最简单）

```bash
git clone https://github.com/stoyanovky/real-estate-tax-tool.git
cd real-estate-tax-tool
open index.html      # macOS
# 或 xdg-open index.html   (Linux)
# 或直接双击 index.html    (Windows)
```

### 方式二：部署为静态站点

任意静态服务器 / Nginx / OSS / GitHub Pages 均可，无需后端。

Nginx 示例：

```nginx
server {
    listen 8080;
    server_name _;
    root /var/www/fdc-tax;
    index index.html;
}
```

## ⚠️ 免责声明

**本工具计算结果仅供参考，不构成任何税务、法律或投资建议。**

1. 税收政策具有**地域性与时效性**，各地执行口径可能存在差异，政策亦会调整
2. 内置地区参数为整理值，**未覆盖或已变更的地区请以当地税务机关口径为准**
3. 复杂交易（如司法拍卖、企业重组、跨境交易等）涉及特殊规则，本工具可能不适用
4. **实际纳税义务以税务机关核定为准**，使用本工具造成的任何后果由使用者自行承担

建议在重要交易前咨询专业税务顾问或主管税务机关。
